Your first weighted estimate

This tutorial estimates the moments of a three-dimensional Gaussian. It introduces the same workflow used by every sampler.

1. Define the log target

using ImportanceSamplers, Random, Statisticslogtarget(x) = -sum(abs2, x) / 2

Here x is the vector being sampled. The function returns $\log\pi(x)=-\lVert x\rVert^2/2$, not $\pi(x)$. The corresponding normalized target is a standard Gaussian in three dimensions.

The omitted normalizing constant does not affect weighted means or variances.

2. Choose a proposal and draw samples

proposal = SphericalGaussian(zeros(3), 1.5)algorithm = ImportanceSampling(proposal; nsamples=20_000)samples = importance_sample(Xoshiro(42), logtarget, algorithm)(size(samples.samples), length(samples.logweights))
((3, 20000), 20000)

The proposal determines the sample dimension. Its second argument is a standard deviation, not a variance. This proposal is wider than the target.

Xoshiro(42) fixes the random stream for this execution environment. nsamples belongs to the algorithm and specifies the exact output count.

The result stores one sample per column: samples.samples[:, i] is the three-dimensional draw at index i.

3. Compute weighted summaries

(    mean=round.(mean(samples); digits=3),    variance=round.(var(samples); digits=3),    covariance=round.(cov(samples); digits=3),)
(mean = [-0.013, -0.006, -0.002], variance = [0.999, 1.01, 0.995], covariance = [0.999 0.01 -0.004; 0.01 1.01 0.003; -0.004 0.003 0.995])

The reference mean is zeros(3). The reference covariance is the identity matrix. The estimates differ because the run has finite size.

These methods use normalized importance weights. In contrast, mean(samples.samples; dims=2) ignores the weights and describes the proposal draws.

Functions of the sampled parameters use the same interface:

(    squared_radius=mean(x -> sum(abs2, x), samples),    first_coordinate_second_moment=mean(x -> x[1]^2, samples),)
(squared_radius = 3.0044261700438586, first_coordinate_second_moment = 0.9989523875964534)

The reference values are three and one, respectively.

4. Inspect the weights

weights = normalized_weights(samples)weight_ess = inv(sum(abs2, weights))(weight_sum=sum(weights), weight_ess=weight_ess, draws=length(samples))
(weight_sum = 0.9999999999999998, weight_ess = 11433.37880523099, draws = 20000)

The raw log weight is

\[\ell_i=\log\pi(x_i)-\log q(x_i).\]

samples.logweights stores these values. normalized_weights returns a new array $\bar w_i=\exp(\ell_i)/\sum_j\exp(\ell_j)$ without changing the raw log weights.

Weight ESS measures concentration. It lies between one and the draw count when the weights are valid. It does not test whether important regions were missed.

5. Estimate the normalizing constant

(    estimate=lognormalizer(samples),    reference=3log(2pi) / 2,)
(estimate = 2.751089765246757, reference = 2.756815599614018)

lognormalizer estimates the logarithm of $Z=\int\pi(x)\,dx$. Here $Z=(2\pi)^{3/2}$, since the target omitted the Gaussian normalization.

Adding a constant to the log target adds that constant to this result. For Bayesian evidence, retain all prior and likelihood normalization constants.
