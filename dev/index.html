ImportanceSamplers.jl

Importance sampling estimates integrals and expectations using weighted draws. ImportanceSamplers provides fixed and adaptive proposals, multiple-proposal methods, and explicit CPU or accelerator execution.

You supply a log target, a normalized proposal, and a random-number generator. The result contains samples and their raw log weights.

Install

Install the package in your project:

using PkgPkg.add(url="https://github.com/JuliaBayes/ImportanceSamplers.jl.git")

Accelerator and automatic-differentiation packages are optional.

Draw weighted samples

Estimate the mean of a three-dimensional standard Gaussian. Its log density is -sum(abs2, x) / 2, up to an additive constant. Each x is a vector of the three parameters being sampled.

using ImportanceSamplers, Random, Statisticslogtarget(x) = -sum(abs2, x) / 2proposal = SphericalGaussian(zeros(3), 1.5)algorithm = ImportanceSampling(proposal; nsamples=10_000)samples = importance_sample(Xoshiro(42), logtarget, algorithm)size(samples.samples)
(3, 10000)

The proposal is a Gaussian with mean zeros(3) and standard deviation 1.5 in each coordinate. The result stores one draw per column, with a matching raw log weight in samples.logweights.

Estimate an expectation

(    mean=round.(mean(samples); digits=3),    variance=round.(var(samples); digits=3),    squared_radius=round(mean(x -> sum(abs2, x), samples); digits=3),)
(mean = [-0.007, -0.007, -0.01], variance = [1.0, 0.994, 0.998], squared_radius = 2.992)

The reference mean is [0, 0, 0], the marginal variances are [1, 1, 1], and the mean squared radius is 3. These estimates use the importance weights. mean(samples.samples; dims=2) ignores them and describes the proposal instead.

For plain IS, each log weight is logtarget(x) - logdensityof(proposal, x). The weights correct for drawing from the proposal rather than the target. The proposal must cover every region that contributes to the expectation. Weight ESS measures concentration, not whether a run found every mode or tail.

Continue the example

Your first weighted estimate samples a three-dimensional target and computes its mean, covariance, and normalizing constant.

Then follow either worked application:

  • Logistic regression: define a posterior, adapt a proposal, and predict a probability.
  • Numerical integration: estimate ordinary integrals, including signed integrands.

Every tutorial defines its data and runs from top to bottom.
