# Signal and background data

These CSV files are copied unchanged from the
[BAT.jl paper example](https://github.com/bat/BAT.jl/tree/3ab3baf1d1666fcd22c08e6f4db3089feec57c39/examples/paper-example).
The adjacent license is copied from that revision.

The benchmark uses the 37 event energies, their detector indices, and the five
detectors' exposures and efficiencies. It does not use the simulated background
rates or event source labels. The model fixes the signal mean at 100 and its
standard deviation at 2, as in the paper example.
