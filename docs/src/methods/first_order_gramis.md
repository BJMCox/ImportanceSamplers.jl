# First-order GRAMIS-CAIS

[`FirstOrderGRAMIS`](@ref) implements a causal first-order GRAMIS-CAIS hybrid
for a fixed population of native Gaussian proposals. Its mean move follows
[GRAMIS](https://arxiv.org/abs/2210.10785); its local covariance fit uses the
ESS-conditioned weighting idea from
[CAIS](https://arxiv.org/abs/1806.00093). The package deliberately differs from
both published algorithms in the ways listed below.

## Target, weights, and causal rounds

The target callable returns an unnormalized **log density** ``\log\pi(x)``.
The sampler never applies `log`. In round ``t``, deterministic allocation gives
proposal ``q_{t,j}`` exactly ``n_{t,j}`` draws and ``N_t=\sum_j n_{t,j}`` total
draws. Every returned sample uses the frozen realized mixture

```math
\psi_t(x)=\sum_j\frac{n_{t,j}}{N_t}q_{t,j}(x),\qquad
\log w_{t,i}=\log\pi(x_{t,i})-\log\psi_t(x_{t,i}).
```

`result.logweights` stores these raw log weights. [`normalized_weights`](@ref)
normalizes all returned rounds together, and [`lognormalizer`](@ref) computes

```math
\log\widehat Z=\operatorname{logsumexp}_{t,i}(\log w_{t,i})-
\log\!\left(\sum_t N_t\right).
```

The linear estimator is conditionally unbiased when the normalized frozen
mixture in every round covers the target's integrable mass, the finite
allocation is fixed before that round's draws, and ``q_t`` depends only on
completed earlier rounds. Unequal round sizes combine with coefficients
``N_t/\sum_sN_s``, which is exactly the flattened all-sample average. Applying
`log` does not preserve unbiasedness, and finite variance additionally requires
the relevant squared ratios to be integrable.

Round ``t`` samples and weights from ``q_t`` first. It then fits local
covariances, evaluates target gradients at the frozen means, applies the
backtracked covariance-preconditioned move and repulsion, and stages
``q_{t+1}``. A result contains samples from ``q_1,\ldots,q_T`` only. The fitted
``q_{T+1}`` is unsampled and retained as learned state.

## Mean, covariance, and repulsion equations

For a sample generated by proposal ``j``, covariance adaptation starts from
the local raw log ratio

```math
\ell_{t,j,i}=\log\pi(x_{t,j,i})-\log q_{t,j}(x_{t,j,i}),\qquad
a_i(\beta)=\frac{\exp(\beta\ell_{t,j,i})}
                  {\sum_k\exp(\beta\ell_{t,j,k})}.
```

The package uses ``\beta=1`` when ``1/\sum_i a_i(1)^2`` meets the configured
ESS threshold. Otherwise bounded bisection selects the largest accepted
``0<\beta<1`` within the tolerance and iteration limit. With raw weights the
covariance is centered at the frozen proposal mean; with tempered weights it is
centered at ``\sum_i a_i(\beta)x_i``. All-zero local weights or failure to find
a positive feasible power retains the old covariance.

For accepted local covariance ``\widehat\Sigma_{t,j}``, rate ``\rho_t``, and
regularization ``\lambda``, the next covariance is

```math
\Sigma_{t+1,j}=(1-\rho_t)\Sigma_{t,j}+
\rho_t\widehat\Sigma_{t,j}+
\lambda\frac{\operatorname{tr}(\Sigma_{t,j})}{d}I.
```

The gradient candidate uses ``\theta\in\{1,1/2,1/4,\ldots\}`` and accepts the
first finite value that does not decrease the log target:

```math
\mu'_{t,j}=\mu_{t,j}+\theta\Sigma_{t,j}\nabla\log\pi(\mu_{t,j}).
```

If every trial fails, ``\theta=0``. Repulsion is computed from the frozen
population and added after this backtracking test. With
``\bar\Sigma_t=M^{-1}\sum_j\Sigma_{t,j}``, a Cholesky factor ``L_t``,
``z_{t,j}=L_t^{-1}\mu_{t,j}``, strength ``\gamma_t``, and softening ``s``,

```math
r_{t,j}=\frac{\gamma_t}{M-1}\sum_{k\ne j}
\frac{\mu_{t,j}-\mu_{t,k}}
     {(\lVert z_{t,j}-z_{t,k}\rVert^2+s^2)^{d/2}},\qquad
\mu_{t+1,j}=\mu'_{t,j}+r_{t,j}.
```

Exact coincident means contribute zero rather than an undefined direction.

## Published rules and package deviations

| Source | Published rule | Package rule |
|:--|:--|:--|
| GRAMIS mean | covariance-preconditioned gradient, backtracking, and raw Euclidean repulsion with proposal-mass products | same first-order gradient shape; pooled-whitened softened distance, fixed unit repulsion masses, and a peer average |
| GRAMIS covariance and order | adapt means and Hessian-based covariances, then sample the adapted population | sample frozen ``q_t`` first; fit ``q_{t+1}`` from that completed round; no target Hessian |
| CAIS weights | raw local weights above the ESS threshold; transformed local weights below it | power-tempered local weights selected by bounded ESS bisection |
| CAIS proposal mean | always adapt the proposal mean with raw normalized importance weights | omit CAIS mean adaptation; move proposal means only through the gradient and repulsion steps |
| CAIS covariance center | center high-ESS covariance on the current proposal mean; center low-ESS covariance on the transformed-weight mean | retain both centering rules: raw covariance uses the frozen proposal mean, while tempered covariance uses its tempered-weight mean |
| Package stabilization | not a paper rule | blend with the old covariance, add a scale-aware ridge, retain the old covariance on bounded fallback, and factor only the accepted candidate |

The independent
[CPU equation reproducer](https://github.com/BJMCox/ImportanceSamplers.jl/blob/main/validation/reproducers/first_order_gramis.jl)
checks the literal GRAMIS repulsion, package repulsion, CAIS raw and tempered
centers, ridge/blend, causal populations, conditional-unbiasedness identity,
and unequal-round combination. The
[CUDA reproducer](https://github.com/BJMCox/ImportanceSamplers.jl/blob/main/validation/reproducers/cuda_first_order_gramis.jl)
records real-hardware CPU agreement, resident repeated execution, bounded
reported transfers, fallbacks, and call-level rollback.

## Derivatives and devices

Derivative selection is fixed during preparation; it is not a runtime fallback.
An explicit `grad` supplied through [`LogTarget`](@ref) overrides interfaces on
the wrapped callable. If both explicit forms apply, `grad!(destination, sample)`
has priority over `grad(sample)`. A bare target requires a first-order
LogDensityProblems interface. An invalid selected source is an error rather
than a fallback to a lower-priority source.

The table is generated during the strict documentation build. Every CPU row
executes the public API in serial and thread-requested modes, twice per prepared
sampler. The matching CUDA validator consumes the same exact rows, evidence
paths, and hardware label.

```@eval
Main.FIRST_ORDER_GRAMIS_CAPABILITY_TABLE
```

These rows use an equal-mass factor-Gaussian population. The complete initial
population contract requires at least two proposals with equal positive masses,
pairwise-distinct means, a common dimension and `Float32` or `Float64` scalar
type, and at least ``d+2`` draws per proposal per round. Spherical, diagonal,
and factor Gaussian forms may be mixed. CUDA execution requires explicit
MLDataDevices transfer before the first call. The A100 validator's supported
contract row is specifically context-free; it is not hardware evidence for this
revision. AMDGPU and Metal are unclaimed.

## Prepared reuse, results, and failures

A successful [`importance_sample!`](@ref) call promotes its unsampled final
population. The next call restarts the configured schedules at round one and
uses that population as its new ``q_1``. [`current_proposal`](@ref) returns an
independent CPU snapshot; accelerator state requires the explicit
`current_proposal(MLDataDevices.cpu_device(), sampler)` form. Earlier results do
not alias later workspaces or proposal snapshots.

Each call is a population transaction. [`FirstOrderGRAMISRoundError`](@ref)
reports the failing round and phase. Failure leaves the population committed
before the call unchanged and returns no partial result, although random
numbers already consumed remain consumed.

The concise end-to-end CPU workflow, including an analytic in-place gradient
and repeated prepared use, is in
[`examples/first_order_gramis.jl`](https://github.com/BJMCox/ImportanceSamplers.jl/blob/main/examples/first_order_gramis.jl).
